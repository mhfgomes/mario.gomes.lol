# mario.gomes.lol

Personal website, link-in-bio, and hardware showcase built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## Content

Edit [`src/content/profile.md`](src/content/profile.md) to update links, about bio, and hardware specs.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
